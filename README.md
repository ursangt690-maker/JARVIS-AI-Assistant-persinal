# JARVIS Android Project

This is a starter Android Studio project for a JARVIS-style personal assistant.

## Included foundation

- Android project structure
- Jetpack Compose UI
- Basic chat interface
- Voice entry placeholder
- Settings entry point
- Microphone and notification permissions
- Modular foundation for AI, memory, wake word, self-talk, Android controls, and security

## Important

This starter does not contain a real Gemini API key and does not pretend that AI, wake-word detection, or Android controls are already implemented.

Add the AI provider securely before enabling live AI requests.

Do not commit real API keys to GitHub.

## Suggested next modules

- Gemini API client
- Speech-to-Text
- Text-to-Speech
- Wake-word engine
- Memory database
- Settings persistence
- Reminder/notification scheduler
- Android action/tool layer
- Secure credential storage
- Full JARVIS UI

## Build

Open this folder in Android Studio and let Gradle sync.

Then run the app on an Android device or emulator.
